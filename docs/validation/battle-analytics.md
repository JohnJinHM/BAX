# 战报可视化验证

验证日期为 2026-11-27，统计口径见[补给分析与玩家统计](../reference/battle-analytics.md)。

| 检查 | 结果 |
| --- | --- |
| 本机旧归档 | 用只读 SQLite 连接复制第 9 版数据库，在副本上运行新版 CLI。786 份战报升级到第 11 版，生成升级前备份，`PRAGMA quick_check` 返回 `ok`。 |
| 补给与雷达基准 | 从原文逐人相加单位补给，7,350 条真人参战记录与玩家总量均相符。升级后的索引重新计算得到 7,311 个有出兵的样本，四项作战均值与标定值一致。 |
| 数据边界 | 自动测试覆盖第 10 版索引回填、当场昵称、转交后补给归属、缺少出生时间、AI、观战者和无法归类型号的补给差额。 |
| 前端交互 | 使用虚构战报在 Edge 预览。1440、1000、720、390 像素宽度下检查出兵两级下钻、返回、存续和批次切换、补给下钻、双向横条、两张雷达图、偏好单位、归档昵称高亮及打开战报。 |
| 自动回归 | `cargo test --workspace`、`cargo clippy --workspace --all-targets -- -D warnings`、`npm run test:ui` 和前端生产构建通过。前端测试覆盖树图面积及不重叠、雷达图的零值与分母、两类偏好样本。 |

## 树图下钻与可调基准

在 Edge 中使用同一份预览战报，以 1440、1000 和 390 像素宽度检查以下交互。

| 检查 | 结果 |
| --- | --- |
| 出兵与补给树图 | 出兵首屏分两队展示十名玩家，两张树图均可逐层打开型号详情。图块按所在位置放大，返回箭头和 Esc 均可逐级返回并恢复焦点。开启减少动态效果后，层级直接切换。 |
| 型号统计 | 自动回归覆盖同型号不同配置的分数与战果合计、转交单位的出兵人与补给持有人，以及同型号中从未消耗补给的实例。 |
| 玩家图表设置 | 核对十二项默认基准，保存自定义数值并重载，作战效能和单位偏好图均使用对应数值。检查零值、越界百分比及恢复默认值后的持久化结果。 |
| 归档名单 | 胜败方各占一排，每个昵称均有边框，当前玩家保留高亮。 |
