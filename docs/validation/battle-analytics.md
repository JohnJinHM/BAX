## 树图下钻与可调基准

在 Edge 中使用同一份预览战报，以 1440、1000 和 390 像素宽度检查以下交互。

| 检查 | 结果 |
| --- | --- |
| 出兵与补给树图 | 出兵首屏分两队展示十名玩家，两张树图均可逐层打开型号详情。图块按所在位置放大，返回箭头和 Esc 均可逐级返回并恢复焦点。开启减少动态效果后，层级直接切换。 |
| 型号统计 | 自动回归覆盖同型号不同配置的分数与战果合计、转交单位的出兵人与补给持有人，以及同型号中从未消耗补给的实例。 |

| 归档名单 | 胜败方各占一排，每个昵称均有边框，当前玩家保留高亮。 |

## 出兵方向、树图索引与玩家刷新

在 Edge 预览战报中以 Bravo 为本方，分别在 1440、1000、390 像素宽度检查。存续时间默认选中，两张时间线使用同一时间刻度。两张树图始终左本方、右对方，逐块求和与各队顶栏的分数、点数一致。核对层级链接、跨级返回、Esc 和返回后的焦点。动效先在原尺寸淡出文字和边线，色块缩放到位后再淡入；减少动态效果时直接切换。

玩家页核对收藏星与昵称的中心线及间距。逐项悬停和键盘聚焦十二条雷达轴，并检查图例和 Esc 关闭。使用预览数据模拟四场有效样本更新到五场，确认橙色提示随样本变化。归档查询框填 8 时点击“刷新资料”，界面仍按 20 场发起查询，同时保留手动输入的 8 场。

## 效能区间、补给重量与共享提示

2026-11-27 以只读方式抽取本机 866 份归档，862 场有时长为正、已出兵且有官方累计出兵分的真人玩家，共 8,081 个玩家场次。按每场累计出兵分除以该场分钟数统计，均值 264.22，中位数 254.00，第 10 和第 90 百分位分别为 199.20 和 341.07 分/分钟。确认采用 200 和 340 作为效率轴的默认低、高值。

用 SQLite 备份接口生成 v11 库副本，并以新版 CLI 打开副本。升级后结构为 v12，生成 v11 备份，`PRAGMA quick_check` 返回 `ok`。8,081 个有效玩家场次的索引出兵分逐条匹配原文。自动回归另覆盖缺失分数、明确的零分和缺少时长的场次。

Edge 预览在 1440、1000、390 像素宽度检查以下交互。

- 两张时间线的顶栏移除计分，出兵分布仍显示双方合计。两张树图的分隔线在文字淡出阶段保持可见。补给树图、单位详情和队友往来统一显示 kg。
- 设置页核对四对低、高值和八项参考占比，交叉或相等的区间无法保存，修改及恢复默认值均可重载。
- 使用低于低值的击毁、落在区间内的占领和高于高值的效率验证图形位置及标注。缺少效率记录时，仍显示其余三轴。两图下方的居中提示在四场有效样本时出现，在五场时消失。
