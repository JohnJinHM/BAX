## 界面检查

使用 `/dev/` 虚构数据，检查 1280×720 与 1000×800 窗口：

- 同时勾选两名玩家，只显示这两名玩家；勾选火炮与固定翼，只显示这两类出兵；全选、清空与 Esc 关闭筛选可用。
- 分区顶栏在主页面滚动时吸附，时间线内部保留时间轴；按玩家、存续时间与双方合并可切换。
- 点击火炮柱条后，仅火炮复选框选中；可继续多选，并切换出兵价值／次数。
- 选图／选卡显示上场专精，加载阶段自动收起；赛后读取本局不同组合。旁观者独立显示，专精留空。
- 详情表包含本局专精列；窄窗口在表格内横向滚动，页面宽度不溢出。PvE 显示 OCR 已暂停。

## 追加交互与伤害统计

- 存续时间普通框选一次选中 4 个单位；Shift 框选保留原单位并追加另一玩家的单位；跨行拖动时预览 7 个单位，按 Esc 后恢复原有 3 个，选择框消失。
- Shift 点击可追加与移除，详情数量随之更新；筛选条件变化后清空选择。
- 玩家展开箭头可点击或按 Enter 开关；嵌套表格悬停仅高亮当前单位行。
- 出兵价值、伤害、损失价值和出兵次数切换可用；伤害模式下的坦克柱条显示 2,320，与该玩家展开明细一致，点击后只勾选坦克。
- 新增 Rust 回归覆盖有效伤害、负值忽略、回收伤害保留、阵亡成本与转交归属。Full 测试、Clippy 和类型检查通过。
- 1280×720 与 1000×800 检查无页面横向溢出；界面截图保存于 `.local/review-20261120/box-selection.jpg` 与 `composition-damage.jpg`。
