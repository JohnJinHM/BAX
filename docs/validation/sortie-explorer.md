## 范围与环境

本次验收覆盖战后分析的浏览器界面与工作区检查。使用 Vite 的虚构对局预览 `/dev/main.html?tab=history&match=8999927`，不连接真实战报、不启动游戏或桌面窗口。未重新打包或验收 Tauri 发布版 exe。

## 检查结果

- 生产构建及 TypeScript 检查通过；11 项前端逻辑与资源完整性测试通过。
- `cargo clippy --workspace --all-targets` 无警告；`cargo test --workspace` 通过。
- 1440px 与 768px 窗口下检查了玩家批次、放大、队伍展开、固定详情和存续时间。此前同时检查了 390px 窗口的页面溢出。
- 玩家视图没有类别图标或类别色条；对应单位图标为白色。缺失资源显示名称。混合批次保留每种型号与各自回收状态，重复型号显示数量。
- 批次角标定位修复后，1440px 样例中的 51 个数量标记均位于所属单位单元左起 46px、顶部 4px；9 个 RTB 标记均位于左起 46px、底部 4px。包括数量和 RTB 同时出现的记录，二者上下分离。放大及切换至 768px 后相对位置保持一致，无溢出。
- 存续时间的普通单位图标保持 44px 宽；无 RTB 最小条宽 54px，有 RTB 为 66px，均无内容溢出。
- 界面机械检查与 `git diff --check` 通过。
