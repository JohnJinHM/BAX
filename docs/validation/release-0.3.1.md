# 0.3.1 发布验收

附注标签 `v0.3.1` 指向 `07570be`。[GitHub Release](https://github.com/JohnJinHM/BAX/releases/tag/v0.3.1) · [Windows 签名构建](https://github.com/JohnJinHM/BAX/actions/runs/46004604136)

## 自定义战报与统计

- 在 Edge 中分别从比赛记录和玩家档案打开多人、自定义及 PvE 战报，核对六种组合。自定义战报展示双方战果、出兵、补给和玩家明细，标题旁标明「不计入玩家统计」。PvE 仍显示归档摘要。
- Rust 回归用例验证自定义战报保留两名参赛玩家、一条出兵记录、补给明细和单独的旁观者名单。该场专精为空，查询近期多人样本时也不会选中该场。
- 本地通过 282 项 Rust 测试、52 项前端测试、rustfmt、Clippy、Vue 类型检查和前端生产构建。

## 数据库升级

用 v0.3.1 CLI 在独立目录将 v12 数据库副本升级至 v13，验证程序生成的 v12 备份可读。逐份比对升级前后 960 份战报的编号和原文 SHA-256，全部一致。新版将其中 866 份归为多人、78 份归为自定义、13 份归为 PvE、3 份归为模式未知。SQLite 完整性与外键检查通过。
