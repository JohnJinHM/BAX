# 0.2.2 发布验收

状态：草案 · 更新：2026-11-21

## 范围

维护者已确认修正后的独立 Debug 版测试没有问题，并授权补充旁观标签、整理数据源文档和发布新版。本次包含游戏数据源优先、BATrace 补充／回退与状态查询、旁观记录标签，以及主线已有的皮肤、边缘吸附和图标更新。继续分发 Full／Lite 签名安装包与便携 ZIP。

## 本机验证

- 灰色“旁”标签按本机 Spectators 队伍显示；默认和断箭皮肤的浏览器预览通过，保留胜、负、弃的区分，无控制台错误。
- 主源字段转换、缓存和回退验证及独立 Debug 启动结果见[数据源兼容性记录](upstream-api-compatibility.md)。
- 前端 34 项测试、Vue 类型检查与生产构建通过。
- 全 workspace 的 248 项 Rust 测试通过（启用 `ocr,installed-updater`），rustfmt 与 Clippy 全 workspace/all-targets 零警告通过。Cargo、Tauri、npm 及两份 lock 文件均为 0.2.2。

## 发布检查

准备推送匹配版本的标签，由工作流构建两版签名安装包与便携包。草稿资产下载、校验、解包和公开结果将在完成后补记。

本机过程日志与下载资产保存在 `.local/release-0.2.2/`。

## 未覆盖的范围

本轮没有完整重做覆盖安装升级、重启及用户数据保留流程；PvE 战报的实时可用性、更多游戏布局及长时间接口稳定性仍未确认。BATrace 故障期间昵称搜索、完整统计与单位目录可能缺失，已有本地记录可继续查看。
