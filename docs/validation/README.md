## 记录方式

1. 开始一项验证时，复制 [template.md](template.md) 为 `NN-简短英文标题.md`，例如 `01-overlay-compat.md`，并把上表的状态改为“进行中”。
2. 验证用的程序放在仓库的 `tools/` 下，或者放在 `spike/` 前缀的分支里。记录中写明对应的提交。
3. 原始数据（日志、抓取的响应、性能采样）放在不入库的 `.local/`。记录里只写汇总数值和脱敏后的片段。
4. 得出结论后更新上表，并处理“结论会影响”一栏列出的文档。结论改变了设计的，新增 ADR。
