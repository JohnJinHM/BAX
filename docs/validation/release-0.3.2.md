# 0.3.2 发布验收

附注标签 `v0.3.2` 指向 `b2337d9`。[GitHub Release](https://github.com/JohnJinHM/BAX/releases/tag/v0.3.2) · [Windows 签名构建](https://github.com/JohnJinHM/BAX/actions/runs/46109630523)

## 玩家搜索与资料

- 在独立的 v13 数据库副本上启动 Full Debug，用昵称、游戏内 ID 和 Steam64 查询 BATrace。搜索结果按需打开，只有打开的玩家会被保存至本地，并触发资料和最近 20 场战局同步。
- 检查本地档案的收藏星标、已收藏筛选和取消收藏后的列表。用带标签的长昵称检查悬浮窗，昵称按宽度省略，悬停可读取全名。
- 发布提交在本地通过 284 项 Rust 测试、52 项前端测试、rustfmt、Clippy、Vue 类型检查和前端生产构建。
- 另行构建了内置前端的 Full Debug。主程序的 Windows 产品版本为 0.3.2，输出目录中的原生 OCR 通过自检。

## 安装包、便携包与应用内更新

- 2026-11-27 21:12（洛杉矶时间）公开发布为 GitHub Latest。Full、Lite 和生成草稿的三项任务均成功。
- 从草稿下载全部八个文件，逐项核对 GitHub 提供的大小和 SHA-256，并核对随包校验清单的六项记录。Full 和 Lite 安装包均通过客户端内置公钥验签，两版更新地址和签名也与清单一致。
- 解包检查四个分发包，主程序版本均为 0.3.2。Full 安装包及便携包中的 OCR 模型摘要与仓库清单一致，原生 OCR 自检通过。两份 Lite 均未包含 OCR 运行时。便携启动器将数据写入相邻的 `data` 目录。本次未在现有安装上执行覆盖升级。
- 发布后匿名访问四个下载地址，均返回 HTTP 200。公开更新入口返回的清单与草稿完全一致，SHA-256 为 `3840946ea5be9c4041aafc8c802cfabed7fe4f1d5f3411cb97f4df4e9512c84e`。
