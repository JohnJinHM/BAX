## 验证结果

- `cargo test --workspace`：203 项通过；Clippy `--workspace --all-targets -- -D warnings` 通过；格式检查通过。
- 干净 worktree 前端测试 11 项通过，TypeScript 检查和 Vite 生产构建通过。
- PyInstaller 成品及安装目录内 EXE 的离线 `--self-test` 均返回 `ready: true`。工作进程在内部禁止网络连接，模型从安装目录读取。
- 同一张 3576×1987 截图识别出 10 张玩家卡片及全部等级。此项验证打包后的推理可用，不代表昵称字符完全正确或俄日文全样本准确率。
- NSIS `/S /D=测试目录` 安装退出码为 0；安装后应用启动，并在模拟等待房间日志下直接启动其 `ocr-runtime/bax-ocr.exe` 子进程。
- v4 升 v5 的自动测试覆盖备份、视图、备注与比赛保留，已有 v5 可重开。
- 当前 v5 数据库的独立副本由新版应用成功打开；打开前后均为 90 名玩家、17 场比赛、1 条备注、11 份战报，`PRAGMA integrity_check` 为 `ok`。正式数据库未修改。

测试数据和构建日志保存在 `.local/`。尚未在完全干净的 Windows 虚拟机验证安装，也未新增游戏实战性能验收。系统缺少 WebView2 时安装器仍需联网安装该系统组件；OCR 无需另装 Python 或下载模型。

构建方法见 [打包指南](../guides/packaging.md)。
