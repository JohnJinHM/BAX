# 专精战报与资料合并验证

状态：生效 · 更新：2026-11-19

## 数据核查

本机资料备份中有 7 项专精经验同为 320000，组合经验也有封顶，无法表示常用顺序。当前资料接口返回 `statInfo: null`；旧刷新逻辑整份替换资料，导致已有统计消失。资料、比赛列表和本机完整战报样本未发现直接的专精场次或所选组合字段。

对本机已有 20 份战报按游戏 1.2.2.1 单位可用性表分析，19 场得到唯一专精组合，1 场存在冲突。样本说明单位约束可以提供逐场结果，也说明近期缓存不等于全历史偏好。原始响应与分析只保存在 `.local/`。

本机数据库先用 SQLite 在线备份保存为 `.local/bax-before-profile-repair.db`，再从既有 v4 备份补回当前资料缺失的 47 个统计字段；当前评分及其他已存在字段保留。此修复仅作用于本机资料，不包含在自动迁移中。
