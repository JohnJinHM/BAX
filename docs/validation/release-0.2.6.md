## 标记与查询框

- 268 项 Rust 测试（含 OCR 与安装更新）、46 项前端测试、rustfmt、Clippy、Vue 类型检查和生产构建通过。默认功能的 Rust 工作区测试也已通过。
- 使用模拟日志和本地 HTTP 服务，按顺序触发日志轮换、接收轮换前产生的 OCR 候选、正式名单到达和标记响应返回。正式名单按玩家 ID 收到 4 次标记。另一用例先返回 HTTP 503，验证同一轮其余玩家仍可取得结果，冷却结束后补查成功。用户反馈的偶发现象尚未在实战中复现。
- 两套皮肤均检查了 OCR 和正式名单、玩家档案，以及标记为正数、零或未知的显示。悬浮窗标记与同一行玩家名的字号均为 13px（100% 缩放）。比赛记录查询框与玩家搜索框的常态和聚焦样式一致，清空查询后恢复比赛列表。
