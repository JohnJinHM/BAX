# 0.2.4 发布验收

状态：生效 · 更新：2026-11-22

## 发布结果

维护者试用修复版后确认切换窗口导致悬浮窗消失的问题通过验收，并要求发布 Release。修复与版本准备已快进合入 `main`，附注标签 `v0.2.4` 指向 `357dccfdce9e34445f174abd9c60bf8bf952b820`。

本次只发布悬浮窗切窗恢复补丁：前台切换后延迟重新置顶；自动恢复意外隐藏、最小化和置顶丢失；主动隐藏后停止恢复；设置显示状态核对原生窗口状态。实现与针对性测试见[悬浮窗恢复验证](overlay-visibility.md)。

[BAX v0.2.4](https://github.com/JohnJinHM/BAX/releases/tag/v0.2.4) 于 2026-11-22 17:51（America/Los_Angeles）公开并设为 Latest，非预发布。[GitHub Actions](https://github.com/JohnJinHM/BAX/actions/runs/45095088712) 的 Full、Lite 与草稿任务全部成功。发布后的文档提交不改变标签与分发文件。

## 本机与 CI 验证

- 本机与两个 Windows runner 均通过 255 项 Rust 测试、41 项前端测试、rustfmt、Clippy、Vue 类型检查和前端生产构建。Rust 检查启用 `ocr,installed-updater`，依赖按 lock 文件锁定；Cargo、Tauri、npm 及两份 lock 文件版本均为 0.2.4。
- 新增 6 项恢复时序测试与 1 项原生窗口回归。原生回归在不切换显示的私有 Windows 桌面验证遮挡、隐藏、最小化、置顶丢失，以及恢复时保持焦点、几何位置和鼠标穿透。
- 维护者已经确认修复版验收；发布期间该程序保持运行，不再另启单实例应用抢占窗口。
