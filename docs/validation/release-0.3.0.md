## 界面与统计

- 52 项前端测试通过。效能轴使用高低值的平均值作为参考虚线，覆盖默认值、修改设置、低值归零及高值以上线性外推。单位偏好仍使用各兵种的参考占比。
- 在 Edge 的 1440、1000、390 像素宽度下，用同一组战报样例检查了参考线位置、轴说明、样本不足提示、设置保存和恢复，以及出兵与补给树图。窄屏一组启用了减少动态效果。
- 出兵、补给、偏好单位和雷达图的计算口径见[战报补给与玩家统计](../reference/battle-analytics.md)。

## 自动化与数据库升级

- 本地通过 281 项 Rust 测试（含 OCR 和安装更新）、rustfmt、Clippy、Vue 类型检查和生产构建。七个 Cargo 工作区包、Tauri 与 npm 声明和锁定的 BAX 版本均为 0.3.0。
- 在隔离目录对真实 v7 备份的副本运行新版迁移。长期库升级到 v12，SQLite 完整性检查通过，生成的 v7 备份可读取。升级前后保有 368 份战报、105 场日志对局、428 名玩家和 7 条内容一致的备注。正式数据目录未参与写入。
