# 玩家与悬浮窗交互验收

2026-11-27，Windows。使用独立 worktree、临时 SQLite 库及 Edge 浏览器预览页。以下场景均已通过，实战叠加效果尚待游戏内验证。

| 场景 | 验证结果 |
|---|---|
| 首次使用和升级 | 清空预览设置后首选「断箭」。两张卡片依次为「断箭」「经典」；选择「经典」后重载仍保留该选择。 |
| 悬浮窗设置 | 显示／隐藏位于第一项。宽度可调至 280 px；预置旧的固定展开高度后，名单仍随内容调整高度。 |
| 昵称与标签 | 280 px 宽度下，长昵称省略，多枚标签可换行，昵称和徽标边界留有间距。作者标签可用键盘聚焦，提示为「是作者哟=w=」。 |
| 收藏 | 用空格操作侧栏星标后，所选档案不变。浏览器刷新和引擎使用同一临时数据库重启后均能读回收藏，取消后可查到最新状态。 |
| 排序与分页 | 最近见过排序下，本机、本局队友和对手、收藏、其余玩家依次排列；验证了跨页边界和切换名字排序。 |
| 当前对局 | 等级与胜率直接可见。赛前和正式名单只有敌方出现预测列，正式名单按 ID 接收国旗。赛后双方显示战报专精，旁观者没有专精列。 |

构建与回归使用 `npm run build`、`npm run test:ui`、`cargo test --workspace`、`cargo test -p bax-engine --features ocr` 和 `cargo clippy --workspace --all-targets -- -D warnings`。
