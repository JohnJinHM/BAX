## 选图选卡阶段显示全部玩家

Full 版已提供赛前识别，实机验收范围如下。 本地 OCR 读取双侧玩家卡片的昵称与等级，优先匹配数据库现有玩家，再查询 BATrace。候选独立展示，日志 ID 到达后更新。方案见 [ADR-0008](../adr/0008-pregame-ocr.md)，测试与数据边界见[验证记录](../validation/pregame-roster.md)。

实机还需确认：真正选图/选卡画面是否使用支持的双侧卡片布局；窗口化、无边框与独占全屏采集；中英俄日和混合名字；悬浮窗遮挡；游戏帧时间影响；对照后续日志核验候选准确率。当前截图验证不能代替这些验收。

## 0.2 实机验收中顺带确认

- 上场专精已接入 OCR 候选与正式名单，后台每局最多补取 5 份敌方最近战报；赛后读取本局组合，个人页统计已有战报场次。验收图标可读性与到达时机，见[口径](../reference/player-specializations.md)。
- 补充 Full / Lite 跨版本覆盖安装与数据保留的端到端检查，见[发布指南](../guides/releases.md)。

- 锁定后悬浮窗保持可见、背景半透明不变黑（锁定改为直接设置 Win32 样式，见[架构](../architecture/overview.md)），在窗口化、无边框全屏和独占全屏下各看一次。

## 皮肤

0.3.0 默认使用「断箭」，另可选「经典」。两套皮肤的预览与窄窗验证见[皮肤验收](../validation/skins.md)和[玩家与悬浮窗交互验收](../validation/player-overlay-qol.md)。

- 不玩游戏时启动桌面应用：切换后两个窗口同时换色，重启后第一帧沿用上次的皮肤。
- “断箭”悬浮窗叠在真实游戏画面上是否清楚，锁定后的半透明底色在亮地图上的可读性。
- 暖橙 `#d98c4c` 是对设计说明里七位色值 `#d98c4ce` 的暂定解释，需要确认。
- 吸附边缘：拖到四条边和四个角松手各试一次；贴着右下角时让悬浮窗自动展开、收起，再改缩放，确认保持贴边、不跑到任务栏下面；多显示器和不同缩放比例下各看一次；关闭开关后不再贴边。

设置已支持调整强调色、本方与对方颜色、胜负颜色、主窗口字号及间距。预览页验证见[个人调整](../validation/skins.md#个人调整)。桌面应用里还要确认：

- WebView2 里取色器的样子，选色后确定与取消；改色后悬浮窗同时换色。
- 字号 130% 时各页在常用窗口大小下的换行，特别是战报两队卡片和当前对局表格。
- 重启后第一帧沿用上次的外观，不先闪一下默认字号或颜色。
