# ADR-0013：通过最近战报补充敌方上次专精

状态：已采纳 · 日期：2026-11-19

用户需要在赛前快速了解敌方专精。资料经验字段封顶，不能表示使用频率；接口样本没有直接的专精场次字段。用户选择“后台补最近一场，额外最多 5 次请求，显示上次专精”。

引擎增加独立任务，等待身份查询完成，使用资料里的最近比赛 ID 补取战报。每局全局预算 5 次，相同战报去重并复用缓存，串行请求完成后间隔 1 秒，错误后本局停止。OCR 与正式名单转换共用同一预算；新比赛重新计数。该任务复用现有 BATrace 客户端的限流状态、战报存储与归档通知，不消耗 OCR 身份查询的 12 次预算。

专精识别在 Rust 中执行，以原出兵单位约束枚举同国专精对，仅唯一解进入统计。前端只展示快照；悬浮窗显示最近已有战报的两枚图标，个人页统计最近最多 20 份已有战报。由此不需要历史批量扫描，也不增加队友查询。具体口径与限制见[专精说明](../reference/player-specializations.md)。
