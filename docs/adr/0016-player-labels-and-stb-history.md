# ADR-0016 玩家标签与 STB 历史战报

2026-11-26 已采纳。更新 ADR-0002 的范围与 ADR-0015 的数据源策略。

主窗口与浮窗的姓名旁统一显示单字，可悬停查看依据。OCR 匹配存在歧义时不展示该账号的标签；日志名单接管后重算队伍关系。

| 标签 | 规则 |
|---|---|
| 挂（红） | 十名真人的完整 5v5 排位战报，净出兵分（出兵分减退款分的 80%）超过 1000 + 5 × 时长秒数。一场即可命中。缺少参赛者出兵数据或至少五人超限时跳过。 |
| 标（黄） | BATrace 社区标记次数为正。 |
| 远（黄） | 时长至少 25 分钟，炮兵击杀加 0.7 倍固定翼击杀至少 30，且占本人至少 45%；或本人至少 10 杀、炮兵占比超过 40%，队友最高占比不超过 20% 或本人超过其两倍。队友比较需要四名队友均有可算的占比。至少三场。 |
| 效（黄） | 本人至少五个单位实例，每实例击杀至少 0.8 且达到其余九人合并基准的 1.6 倍，至少五场。 |
| 小（黄） | 等级低于 30 且 ELO 高于 2000，或等级低于 50 且 ELO 高于 2500。 |
| 空（黄） | 最近连续三场有效排位，每场固定翼消耗超过该场本队补给总消耗的 40%。有无法识别模式或阵容的历史缺口时不确认连续性。仅在当前敌方存在至少三人车队时显示。 |
| 车（蓝） | 当前同侧的同一组合在历史排位中反复整组同队。二至四人须三场，五人须两场。提示整组成员和同队场次。 |

标签注释先写计算方式。涉及战报的标签按开局时间从近到远列出命中场次，用本地日期、时间与地图表示每场。「效」列本人和其余九人每单位的平均击杀，「空」列本人固定翼占全队补给的比例。「标」与「小」直接显示账号的标记次数或等级和 ELO。

战报规则使用近期最多 15 场有效排位。缺少近期 ID 时使用已归档样本，连续三场的条件需要近期列表。战报、玩家资料和近期 ID 使用 STB。STB 故障时沿用已有资料与已归档战报。BATrace 用于社区标记、陌生昵称搜索、单位与专精目录。

玩家页「刷新过往对局」读取 STB 返回的近期 ID，按 ID 复用完整归档，收录其余有效战报。查询数量默认 20 场，可指定 1 至 100 场。每次手动发起查询时，按玩家记录时间。停止会取消在途网络请求，保留已经写入的战报。

归档战报使用比赛记录页的单字标签，并按所选玩家的视角预览。「本」表示本机日志记录过这场比赛。「同」表示另一名玩家与本机账号出现在同一场比赛的名单中，可由本地日志或归档战报确认。支持按地图、标签或专精筛选。收录其他玩家的历史不会增加日志同场计数。
