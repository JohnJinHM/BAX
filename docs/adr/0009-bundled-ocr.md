# ADR-0009：随安装包分发离线 OCR 运行时

原生 OCR 分支的打包实现由 [ADR-0010](0010-native-fixed-region-ocr.md) 取代；本文保留先前方案记录。

状态：已采纳 · 日期：2026-11-19 · 替代 ADR-0008 中的运行时安装方式

## 背景

用户要求一键安装后直接使用 OCR，并兼容已升级至 v5 的本地数据库。

## 决定

- 用 PyInstaller 的 onedir 模式生成 `bax-ocr.exe`、解释器及依赖，配合三个固定 SHA-256 的模型，通过 Tauri 资源映射安装到 `ocr-runtime/`。用户无需安装 Python 或手动下载模型。
- 发布版只调用随包运行时；开发调试仍可使用本地 Python 环境。OCR 进程显式指定本地模型路径，并禁止网络连接，模型缺失时报告安装损坏。
- 模型和依赖只在构建机器下载。打包附带 Python、依赖包与模型许可声明，以及版本和模型哈希清单。构建后必须对独立 EXE 执行离线自检。
- v5 使用主分支已有的同一条 `cancelled_matches` 视图迁移。v4 升级前保留备份；现有 v5 直接打开，不降低结构版本、不替换数据库。

## 后果

安装包变大，但 OCR 首次启动不需要安装环境或联网下载模型。WebView2 仍由安装器按需安装；BATrace 在线查询仍需要联网。单文件自解压模式会增加启动延迟和临时文件开销，因此不采用。
