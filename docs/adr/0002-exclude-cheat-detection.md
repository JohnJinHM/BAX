# ADR-0002：首阶段排除作弊与异常行为判定

- 状态：已采纳
- 日期：2026-11-16
- 相关：[项目规划·已确定事项](../planning/project-plan.md#已确定事项)

## 背景

原型包含一个检测模块 `src/elo_cheat_check.py`，以及与之配套的标签、告警和检测详情页，另有自动组排推断。规划阶段确定 BAX 首阶段不包含这部分功能。

## 决定

首阶段不包含：

- 反作弊、疑似作弊、小号和异常行为的判定；
- 与上述判定相关的标签、告警和检测详情页；
- 原型中的自动组排推断。

保留：

- 出兵、击杀、损失、补给等客观统计，用于描述玩家风格；
- 用户自己写的备注，独立于接口数据保存。

## 后果

- `elo_cheat_check.py` 中的检测规则和扫描流程不移植。其中比赛列表查询、单位目录映射等数据处理思路可以单独提取，用于客观统计。
- 统计结果只呈现数值、样本场数和时间范围，不给出对玩家的结论性判断。
- 数据模型和界面不为检测结果预留字段或入口。以后要纳入这类功能，需要新的 ADR。
