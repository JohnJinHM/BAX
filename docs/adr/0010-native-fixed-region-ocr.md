# ADR-0010：独立 OCR 分支使用原生固定区域识别

状态：已采纳 · 日期：2026-11-19

替代 ADR-0009 中 Python 工作进程的打包实现，保留其离线分发及数据库兼容约定。

## 决策

`codex/ocr-native` 作为独立 OCR 版本，从 `main` 合并通用修复；不把 OCR 改动合回标准版。同步是显式 Git merge，不自动修改远端或定时更新。

使用独立 C++ 工作进程和 ONNX Runtime CPU，通过既有 JSON 行协议与 Rust 引擎通信。Rust 成员继续禁止 unsafe。C++ 内的 Windows 采集使用 Win32/GDI，离线图片读取使用系统 WIC，不依赖 Python、OpenCV、NumPy。编译使用静态 MSVC 运行库。

按双侧五行卡片的归一化区域裁剪昵称与等级，只分发中英日及俄文文字识别模型，不分发检测、方向分类模型。缺少双侧有效卡片、分辨率或布局不受支持时不发布名单。固定区域仅覆盖已验证的加载/部署布局，其他阶段继续等待日志名单，不能据此宣称所有准备界面均可识别。

候选继续只使用昵称与等级，本地资料优先，日志 ID 到达后替换。截图不保存、不上传；诊断不输出真实昵称。离线图片测试输出仅存入 `.local/`。

## 验证

同一截图与降采样版本验证卡片、等级及昵称；记录模型初始化与预热后耗时。虚构名单图片与空白图测试区域边界、解码、误识别拒绝；运行现有 Rust 和前端测试，实际生成含原生运行时的安装包。未收集到的真实俄日文、超宽屏和其他卡片布局列为未验证。
