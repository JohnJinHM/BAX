# 自定义与 PvE 对局

状态：生效 · 更新：2026-11-27

正式名单按日志中的 Alpha、Bravo、Spectators 分组，双方人数分别统计。悬浮窗与当前对局详情列出旁观者，均分与双方比较只计算参赛玩家。战报或日志名单中出现旁观者时，整份战报归入自定义。

比赛记录侧栏在本机队伍为 Spectators 时显示灰色“旁”标签；胜负未知但未确认旁观的比赛不显示该标签。

战报 `Type=1` 表示自定义，默认值 0 表示排位。实时日志出现旁观者时标为自定义；其余对局先显示实际人数，收到战报后补充模式名称。人数不足五人不影响正式名单接管 OCR。

场景名称以 `_Skirmish` 结尾，或日志名单出现负 ID 的 AI 时，当前对局标为 PvE。引擎取消 OCR 任务、退出识别进程、清空候选，并停止上场专精补查；OCR 设置保持原值，下一场 PvP 自动恢复。识别模式前沿用用户的 OCR 设置。AI 仅提供模式线索，玩家档案仍使用真人 ID。

多人对战（排位）和自定义比赛均显示单场战报图表，PvE 和未确认模式的战报显示归档摘要。专精识别、战报标签、雷达及偏好单位只采用多人对战样本。数据库第 13 版从已有战报回填模式，并结合日志场景、AI 和旁观者记录判定。验证样本和下一轮实机验收见[验证记录](../validation/match-analysis-polish.md)。
