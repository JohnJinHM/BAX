# 战报补给与玩家统计

## 补给分析

补给消耗矩形树图顶部显示全场和两队的整数点数。队伍合计来自参战者的 `SupplyPointsConsumed`，包含有战报的 AI。按消耗单位的最终持有者读取 `UnitData.TotalSupplyPointsConsumed`，跳过观战者。战报省略的零值按 0 处理。缺少玩家总量时采用其单位之和，玩家总量超过明细时将差额列入“其他 / 未归类消耗”。

全场按队伍和兵种切块，本方固定在左。每队顶栏显示总点数，方块内标注点数和本队占比。顶部路径中的全场、队伍、兵种和玩家均可从更深的层级直接返回。选择兵种后，按该队的玩家和具体型号切块。两层的百分比均以整队消耗为分母。选择具体型号后可查看实际消耗过补给的实例数及其战果、回收和伤害等记录，同时显示该型号占玩家和本队的消耗比例。未归类差额仅显示有记录的点数与占比。转出记录只描述部署，不重复计补给。时间线筛选只作用于出兵分析。

补给往来的每一行以该玩家为视角。中央向左为其使用队友的补给（`SupplyPointsConsumedFromAllies`），向右为队友消耗其提供的补给（`SupplyPointsConsumedByAllies`）。左右以及两队共用全场最大值作为刻度。

## 偏好单位与归档名单

玩家档案的“刷新资料”同时查询最近 20 场对局。已有战报直接复用，归档区可停止正在运行的查询，也能单独指定查询场数。

专精使用下方依次展示偏好单位和开局偏好。取最近 20 场参战归档，按基础型号出现的场数排序，展示前五名。每场同型号最多计一次。偏好单位使用有部署明细的场次，开局偏好使用有出兵时间可供判断的场次，时间窗为正式开局前至开局后第 180 秒之前。每项列出场数、有效样本数和出场率。

归档行分两排显示胜方与败方，每个昵称有独立边框，较窄窗口内同队昵称可换行。胜负未知时按队名列出。高亮依据当前打开的玩家 ID，昵称优先取当场战报。ELO 涨跌以正负号和颜色表示。数据库第 11 版在升级事务里从旧战报原文重建玩家索引，更新战报时同步替换索引。
