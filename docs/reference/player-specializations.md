# 常用专精（试运行）

状态：生效 · 更新：2026-11-19

玩家资料的 `statInfo.specExp` 提供专精累计经验，`combinedSpecsExp` 提供组合累计经验。两项分别从高到低取前三，经验相同按专精 ID 排序。占比的分母包含所有有效项，不仅是前三项。它们是累计经验倾向，不是使用场数、近期使用率或本场所选专精。

只接受正数经验和正整数 ID；组合必须包含两个不同 ID。反向组合键归一后取较大的经验，不重复累加。未知 ID 显示“专精 #编号”；缺失、null、空表、只有零或负数时显示暂无数据，不用等级补猜。

专精名称来自 BA-Units 游戏 1.2.2.1 的 `Specializations` 与中文本地化表，精简目录随应用打包为 `crates/bax-engine/src/specializations.json`。更新游戏版本时同步这份目录，不调用专精目录网络接口。

计算在 `ProfileSummary::from_response` 内完成。OCR 候选本地命中或取得资料后立即带上统计，正式日志玩家和档案复用同一转换。无额外远端请求、不改队友只查本地的规则、不扫描历史战报。旧缓存原文读取时重新提炼，不需迁移数据库或重新下载。

展开悬浮窗在昵称下显示经验最高的一项，悬停可看前三项；玩家详情列出前三项、占比及组合。OCR 有歧义时沿用既有规则，不展示候选资料统计；临时身份仍待日志确认。
