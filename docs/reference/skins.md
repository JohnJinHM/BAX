# 皮肤变量

状态：生效 · 更新：2026-11-21

皮肤机制见 [ADR-0014](../adr/0014-skins.md)。本文列出皮肤可以覆盖的变量、内置皮肤的取值依据，以及新增皮肤的步骤。变量的默认值以 [`theme.css`](../../src/shared/theme.css) 为准，“断箭”的取值以 [`broken-arrow.css`](../../src/shared/skins/broken-arrow.css) 为准，这里只说明用途。

## 基础变量

| 变量 | 用途 |
|---|---|
| `--bax-font`、`--bax-mono` | 正文字体、路径等等宽文字 |
| `--bax-bg-rgb` | 底色的 RGB 三元组；悬浮窗按设置里的不透明度与它组合 |
| `--bax-surface` | 卡片、导航等面板；可以半透明 |
| `--bax-surface-2` | 面板上的输入框、按钮、下拉、图表提示框 |
| `--bax-fg`、`--bax-soft`、`--bax-muted` | 主要文字、出兵分析里的次要文字、说明与标签 |
| `--bax-faint` | 坐标轴、禁用与最次要的标注，不承担需要阅读的文字 |
| `--bax-border`、`--bax-divider` | 面板与表格的线、单位明细里更淡的分隔线 |
| `--bax-accent`、`--bax-on-accent` | 强调色与主按钮上的文字 |
| `--bax-friend`、`--bax-foe` | 知道本机队伍时的本方、对方 |
| `--bax-alpha`、`--bax-bravo` | 不知道本机队伍时的两队 |
| `--bax-good`、`--bax-warn`、`--bax-bad` | 胜利与成功、提醒与备注、失败与错误 |
| `--bax-radius`、`--bax-radius-sm`、`--bax-radius-xs` | 面板、控件与列表行、标签与小块的圆角；更小的圆角取 `min(固定值, --bax-radius-xs)` |
| `--bax-select-chevron` | 下拉框的箭头图案；数据 URL 不能引用变量，每个皮肤按自己的文字色给一份 |

## 组件变量

默认由基础变量推出，皮肤可以单独覆盖。标“不显示”的默认值不占位置，默认皮肤的布局不受影响。

| 变量 | 用途 | 默认 |
|---|---|---|
| `--bax-app-bg` | 主窗口背景，可以是渐变 | 底色 |
| `--bax-surface-solid` | 吸顶区域的不透明面板色 | 同 `--bax-surface` |
| `--bax-row-hover` | 行悬停 | 强调色 8% |
| `--bax-selected-bg`、`--bax-selected-edge` | 列表里选中的一项与它左侧的窄边 | 强调色 12%；不显示 |
| `--bax-self-bg`、`--bax-self-edge` | 名单里的本机玩家与左侧窄边 | 强调色 10%；不显示 |
| `--bax-value` | 计时、两队均分、战报得分、玩家 ELO 这类最重要的数值 | 主要文字色 |
| `--bax-overlay-value` | 悬浮窗里的计时与对局状态、收起时的两队均分 | 同 `--bax-value` |
| `--bax-brand` | 导航栏的 BAX 字样 | 强调色 |
| `--bax-nav-bg`、`--bax-nav-active-bg`、`--bax-nav-active-edge` | 导航栏、选中的导航项与它的标记边（窄屏时在下方） | 面板；面板 2；不显示 |
| `--bax-heading-mark`、`--bax-heading-mark-color` | 分区标题前短竖线的宽度与颜色 | 0（不显示）；强调色 |
| `--bax-overlay-fade-alpha`、`--bax-overlay-fade-width` | 悬浮窗背景左侧的渐变：左边缘不透明度 = 设置的不透明度 × 系数，到这个宽度处恢复设置的不透明度 | 1；0%（纯色） |
| `--bax-overlay-border`、`--bax-overlay-unlocked-border` | 悬浮窗锁定时、解锁时的边框 | 细实线；强调色虚线 |

## 内置皮肤

| ID | 名称 | 说明 |
|---|---|---|
| `default` | 默认 | 皮肤功能之前的界面：深蓝灰底色、蓝色强调、圆角面板 |
| `broken-arrow` | 断箭 | 参照游戏战场 HUD 与图鉴界面 |

“断箭”以项目负责人的设计说明（v0.5，依据 PlayCraft 的游戏画廊截图整理）为起点，再按负责人看过实机构建后的要求调整（2026-11-21），不是游戏官方的设计规范：

- 背景 `#0f0f0f`，右上方用面板色做一处很淡的径向提亮；面板 `#21221f`，直角，细线分隔；浅色文字 `#e7f8e5`。面板 2 取 `#262723`，再亮就会让对方红低于 4.5:1。
- 黄色 `#f4d42a` 是主强调色，只用在选中的导航、选中对象和本机玩家的窄边、主按钮、计时与均分等关键数值上，靠覆盖面积控制层次；选中行本身用中性提亮，不铺黄色。
- 暖橙 `#d98c4c` 是第二强调色：提醒、备注、准备阶段倒计时，以及表格行悬停（25%）。设计说明里给的是七位的 `#d98c4ce`，不是合法的颜色值，暂按 `#d98c4c` 处理，待负责人确认。
- 本方蓝 `#62a8e5`；敌方红 `#ff4949`，不知道本机队伍时 Bravo 也用它。失败色 `#f26b5f`。
- 悬浮窗不画边框，解锁时也不画虚线；背景按设置的不透明度，左侧一半从透明渐变过来。悬浮窗叠在游戏画面上，计时、对局状态与均分用浅色文字 `#e7f8e5`，不用黄色。
- 英文与数字用 Inter（`@fontsource-variable/inter`，随应用打包，按字符集分块，只在用到时加载），中文与默认皮肤一样用微软雅黑。

## 新增皮肤

1. 在 [`skins.ts`](../../src/shared/skins.ts) 的目录里加一项，写 ID、名称和一句说明。
2. 新建 `src/shared/skins/<id>.css`，只写一个 `[data-skin="<id>"]` 块，覆盖需要的变量；在同目录的 `index.css` 里 `@import`。
3. 需要表达现有变量做不到的差异时，先在 `theme.css` 的组件变量里加一个默认不改变现状的变量，组件改用它，再在皮肤里覆盖，并补进本文的表格。
4. 运行 `npm run test:ui`：检查目录与文件一一对应、皮肤只声明已有变量，以及每个皮肤的文字色在底色、面板、面板 2 上达到 4.5:1，主按钮文字在强调色上达到 4.5:1。
5. 用预览页 `/dev/main.html?skin=<id>&tab=…` 与 `/dev/overlay.html?skin=<id>` 逐页查看，悬浮窗还要看 `?ended`、`?pregame` 和收起状态。
